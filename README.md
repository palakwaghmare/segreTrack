# SegreTrack

A beginner-friendly smart waste management community project website.

## Features
- Waste segregation guide (wet, dry and e-waste)
- Waste report form and browser-local dashboard
- Household H101 QR demo with saved segregation status
- Complaint submission and local complaint list
- Five-question waste segregation quiz
- Local demo leaderboard for quiz scores
- Responsive layout for mobile and desktop

## Run locally
Open `index.html` in a modern browser. An internet connection is needed for the optional QR-code library and Google Fonts CDN. Reports, complaints, household status and scores are saved in the browser's `localStorage` on the device being used.

## Important demo limitation
This is a front-end educational prototype. Data is not shared between devices or users, and complaints are not sent to a municipal authority. A real multi-user deployment needs a backend/database and an authorized complaint-handling workflow.
